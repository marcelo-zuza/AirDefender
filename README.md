# Air Defender 🎮

A thrilling 3D arcade-style flight combat game inspired by Star Fox, built with **Unity 6** and **C#**.

## 📋 Overview

Air Defender is an action-packed aerial combat game where players pilot a fighter jet across a beautiful low-poly island landscape. Destroy all ground targets while evading enemy fighter jets in intense dogfights. Master the skies and complete the mission!

## 🎯 Gameplay Features

- **Dynamic Flight Combat**: Pilot a responsive fighter jet with smooth, arcade-style controls
- **Ground Target Destruction**: Locate and eliminate enemy installations scattered across the island
- **Enemy AI**: Engage with intelligent enemy fighters that pursue and attack strategically
- **Low-Poly Aesthetics**: Beautiful minimalist art style that runs smoothly on various systems
- **Island Exploration**: Fly freely across a detailed low-poly environment with varied terrain
- **Scoring System**: Earn points for destroying targets and defeating enemies

## 🎮 Controls

| Action | Control |
|--------|---------|
| Move | WASD / Left Stick |
| Aim | Mouse / Right Stick |
| Fire Weapon | Left Click / LT |
| Roll | Q/E or LB/RB |
| Boost | Spacebar / A Button |

## 🛠️ Technical Details

- **Engine**: Unity 6
- **Language**: C#
- **Graphics**: Low-poly 3D
- **Platform**: PC (Windows/Mac)

## ✨ Key Systems

- Advanced flight physics for responsive controls
- Particle effects for weapon impacts and explosions
- Dynamic camera system following the aircraft
- Audio feedback for impacts and combat actions
- Performance-optimized rendering
